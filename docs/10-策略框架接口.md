# 10 — 策略框架接口（Strategy SDK）

**文件目標：** 定義「如何寫一個 EightiQuant 策略」。任何實作了本文檔接口的 Go 包，都可作為策略掛接到 framework，無需修改 framework 程式碼。

---

## 1. Strategy 接口（最小契約）

```go
// internal/strategy/strategy.go
package strategy

type Strategy interface {
    // 元資訊
    Manifest() Manifest

    // 主決策入口（純函數）
    Step(input StrategyInput, params Params) StrategyOutput

    // 預設參數（不進化的策略用此；進化策略也可作為 GA 種子）
    DefaultParams() Params
}

type Manifest struct {
    ID                string   // "lunar-spot-v1" / "simple-dca" / "grid"
    Name              string   // 給 UI 顯示的友善名稱
    Version           string   // 語意版本，如 "1.0.0"
    IsSpot            bool     // 現貨 / 合約（當前 framework 僅支援 spot=true）
    SupportedSymbols  []string // ["BTCUSDT", "ETHUSDT"] 或空陣列代表「任意 symbol」
    RequiredDataKind  string   // "close-only" / "ohlcv"（當前 framework 僅 close-only）
    MinWarmupBars     int      // 最少需要多少根歷史 bar 才能跑 Step()
    AggregationInterval string // "1h" / "4h" / "1d"
    SupportsEvolution bool     // true → 該策略需實作 EvolvableStrategy 接口
}
```

**鐵律**：
- `Step()` 必須是純函數（無 I/O、無時鐘、無隨機）
- `Step()` 內**禁止** `if isPaperMode { ... } else { ... }` —— Paper / Live 同構
- `Step()` 不能讀取 `input.NowMs`，所有時間判定用 `input.LatestBarTimeMs`（= bar close 時間戳）

## 2. StrategyInput / StrategyOutput

```go
// internal/strategy/io.go

type StrategyInput struct {
    // 時間（一律 ms，UTC）
    NowMs           int64    // 僅供 diagnostics，禁止參與決策
    LatestBarTimeMs int64    // 最新已完成 bar 的「收盤」時間戳

    // 歷史價格（已 ACL 為 close-only 策略降級）
    Closes     []float64 // 升序，至少 Manifest.MinWarmupBars 根
    Timestamps []int64   // 與 Closes 同長

    // 即時市價（順勢價，下單轉換用；策略內核可以參考但避免做時間判定）
    LivePrice float64

    // 帳戶快照
    Portfolio PortfolioSnapshot

    // 策略內部運行時狀態（持久化於 DB，由上次 Step() 產出）
    Runtime RuntimeState  // type alias for any (json blob in DB)

    // 標的元資訊（給下單轉換、不參與決策）
    Symbol      string
    LotStepSize float64
    LotMinQty   float64
    MinOrderUSD float64

    // Mode flag（僅 framework 用，**策略不得讀取**）
    // 設計上不放在 input 裡，由外圈處理；此處註明僅為避免遺漏
}

type PortfolioSnapshot struct {
    USDTBalance     float64
    DeadAsset       float64
    FloatAsset      float64
    ColdSealedAsset float64
    Lots            []LotEntry  // 每個 lot 的詳細
}

type LotEntry struct {
    ID            uint
    Type          string  // "DEAD" / "FLOAT" / "COLD_SEALED"
    Qty           float64
    BuyPriceUSDT  float64
    BuyTimeMs     int64
    IsColdSealed  bool
}

type StrategyOutput struct {
    Intents     []TradeIntent
    Releases    []ReleaseIntent
    NewRuntime  RuntimeState
    Diagnostics map[string]float64 // 給 UI 顯示用，如 {"signal": 0.32, ...}
}

type TradeIntent struct {
    Action     string   // "BUY" / "SELL"
    Engine     string   // 由策略自定義（如 "MACRO" / "MICRO" / "GRID_FILL"）
    LotType    string   // "DEAD" / "FLOAT"（新買入歸入哪一籃）
    AmountUSDT float64  // BUY 用
    QtyAsset   float64  // SELL 用
}

type ReleaseIntent struct {
    Kind          string         // "soft_release" / "hard_release"
    Slices        []ReleaseSlice // 每個 slice 對應一個 lot 的釋放量
    TotalQtyAsset float64

    // hard_release 必填：對應的 TradeIntent 在 StrategyOutput.Intents 中的 index（0-based）
    // soft_release 設為 -1（無對應 SELL）
    //
    // 為何不用 client_order_id？因為 client_order_id 由外圈 Phase C 翻譯時才生成，
    // Step() 純函數無法存取。改用 intent index 在 Step() 內穩定串聯，
    // 外圈翻譯時把 index → client_order_id 並回填到 release 紀錄。
    RelatedIntentIndex int
}

type ReleaseSlice struct {
    LotID uint
    Qty   float64
}

// Params 是策略自訂的參數結構，type alias for any
// 不進化的策略：strategy.DefaultParams() 直接 return 寫死的 struct
// 進化的策略：實作 EvolvableStrategy 接口，由 GA 注入
type Params any
```

## 3. EvolvableStrategy 接口（可選）

策略若 `Manifest.SupportsEvolution == true`，必須額外實作此接口：

```go
// internal/strategy/evolvable.go
type EvolvableStrategy interface {
    Strategy

    // GA 8 動詞契約（見 20-進化計算引擎.md §8）
    Sample(rng *rand.Rand) Gene
    Mutate(g Gene, prob, scale float64, rng *rand.Rand) Gene
    Crossover(p1, p2 Gene, rng *rand.Rand) Gene
    Fingerprint(g Gene) uint64

    Evaluate(ctx context.Context, g Gene, plan EvaluablePlan) EvaluateResult

    DecodeElite(paramPackJSON []byte) Gene
    EncodeResult(g Gene, spawn SpawnPoint) []byte

    Verify(ctx context.Context, g Gene, spawn SpawnPoint, bars []float64,
           lotStep, lotMin float64) BacktestMetrics
}

type Gene any  // 不透明載體，引擎不讀取內部欄位
```

策略不需 GA（如 `simple-dca`）就**不實作**此接口，`Manifest.SupportsEvolution = false`，cron tick 直接走 `DefaultParams()`。

## 4. Building Blocks（可選用的工具庫）

framework 提供常用算子，策略可隨意組合或不用。**building blocks 也是純函數**。

### 4.1 信號計算器 `internal/quant/signals/`

```go
// signals/signal.go
type Signal interface {
    // 計算當前訊號值（無量綱化）
    Value(closes []float64, params SignalParams) float64
}

// 內建實作：
type EMABaseDeviation     // 對 EMA 的偏離
type LogReturnVelocity    // log return 一階導
type LogReturnAcceleration // log return 二階導
type BreakoutAboveHigh    // 突破近 N 根高點
type MeanReversionZScore  // 偏離 z-score
```

策略可以挑一個或多個 Signal，加權合成自己的 `Signal` 標量送進 Sigmoid。

### 4.2 市場狀態偵測器 `internal/quant/regimes/`

```go
// regimes/regime.go
type RegimeDetector interface {
    Detect(closes []float64, params RegimeParams) Regime
}

type Regime struct {
    Label   string             // 策略自定義（如 "panic" / "greed" / "quiet"）
    Modifiers map[string]float64  // 給策略各引擎用的調整係數
}

// 內建實作：
type SJMThreeState   // 平靜 / 貪婪 / 恐慌（lunar-spot-v1 用）
type FourState       // bull / bear / quiet / extreme（給更複雜策略用）
type AlwaysQuiet     // 不做狀態偵測，永遠回傳 quiet（simple-dca 用）
```

### 4.3 倉位管理引擎 `internal/quant/engines/`

## 5. 策略註冊與實例綁定

### 5.1 註冊
策略包在 `init()` 註冊到 framework：

```go
// strategies/lunar-spot-v1/init.go
package lunarspotv1

import "github.com/Chuanyin1202/eighti-quant/internal/strategy"

func init() {
    strategy.Register(&Strategy{})
}
```

### 5.2 用戶建立 Instance
```
POST /api/v1/instances
{
  "strategy_id": "lunar-spot-v1",
  "symbol": "BTCUSDT",
  "mode": "paper",
  "spawn_point": { ... }
}
```
SaaS 驗證 `strategy_id` 已註冊、`symbol` 在 `Manifest.SupportedSymbols` 內、`mode` 合法。

## 6. 寫一個新策略：5 分鐘上手範例

最小可跑策略：`HelloStrategy`（每月 1 號花 100 USDT 買入）

```go
// strategies/hello/strategy.go
package hello

import (
    "github.com/Chuanyin1202/eighti-quant/internal/strategy"
    "time"
)

type Strategy struct{}

func (s *Strategy) Manifest() strategy.Manifest {
    return strategy.Manifest{
        ID:                  "hello",
        Name:                "Hello Strategy（範例）",
        Version:             "1.0.0",
        IsSpot:              true,
        SupportedSymbols:    nil, // 任意 symbol
        RequiredDataKind:    "close-only",
        MinWarmupBars:       1,
        AggregationInterval: "1d",
        SupportsEvolution:   false,
    }
}

func (s *Strategy) DefaultParams() strategy.Params {
    return Params{MonthlyAmountUSDT: 100.0}
}

type Params struct {
    MonthlyAmountUSDT float64
}

type RuntimeState struct {
    LastBuyMonth string // "2026-05"
}

func (s *Strategy) Step(in strategy.StrategyInput, p strategy.Params) strategy.StrategyOutput {
    params := p.(Params)
    runtime := decodeRuntime(in.Runtime)

    bartime := time.UnixMilli(in.LatestBarTimeMs).UTC()
    yearMonth := bartime.Format("2006-01")
    isFirstDay := bartime.Day() == 1

    out := strategy.StrategyOutput{NewRuntime: runtime}

    if isFirstDay && runtime.LastBuyMonth != yearMonth {
        out.Intents = []strategy.TradeIntent{{
            Action:     "BUY",
            Engine:     "DCA",
            LotType:    "DEAD",
            AmountUSDT: params.MonthlyAmountUSDT,
        }}
        runtime.LastBuyMonth = yearMonth
        out.NewRuntime = runtime
    }

    return out
}

// init.go
func init() { strategy.Register(&Strategy{}) }
```

**就這樣**。25 行 Go code，一個能跑的 DCA 策略。

## 7. 鐵律檢查清單

實作策略後必驗：

```bash
# 1. 純函數鐵律（每個策略包獨立檢查）
rg -n '(net/http|database/sql|gorm\.io/|os\.(Open|Create)|time\.(Now|Sleep)|math/rand)' \
   strategies/<策略名>/

# 2. 標的中立（不能 if symbol == "BTCUSDT"）
rg -n '"BTCUSDT"|"ETHUSDT"' strategies/<策略名>/
# 例外：Manifest.SupportedSymbols 字面量允許

# 3. Mode 中立（不能 if isPaperMode）
rg -n 'isPaperMode|PaperMode|LiveMode' strategies/<策略名>/

# 4. NowMs 不洩漏（決策時間用 LatestBarTimeMs）
rg -n 'in\.NowMs|input\.NowMs' strategies/<策略名>/
# 例外：Diagnostics 輸出可用

# 5. 無 if isBacktest
rg -n 'isBacktest' strategies/<策略名>/
```

任一 grep 出現非空結果（除註明例外）→ 違反鐵律。

## 8. 策略測試指引

每個策略**必須**附帶以下測試：

| 測試類型 | 檔案位置 | 內容 |
|---------|---------|------|
| 確定性測試 | `step_test.go` | 相同 input 兩次呼叫 output 相同 |
| Sigmoid 符號驗證（如使用） | `sigmoid_sanity_test.go` | 三組 case：看空 / 看多 / 弹簧拉回 |
| 因子相關性檢查（如使用 GA） | `factor_collinearity_test.go` | 對歷史 BTC/ETH 數據算 VIF < 5 |
| Warm-up 邊界 | `warmup_test.go` | `len(Closes) < MinWarmupBars` 應 return 空輸出 |
| 模式同構 | `mode_invariance_test.go` | Paper / Live 接同樣 input 應產生同樣 intent |

## 9. 結論

EightiQuant 的核心承諾：**只要實作 `Strategy` 接口，你的策略就能跑在這個 framework 上**——免費獲得 GA 進化、Paper trade、cron 調度、帳本管理、reconcile 機制、前端 dashboard 等所有工程基礎。

具體 reference 實作見 `strategies/` 子目錄。
